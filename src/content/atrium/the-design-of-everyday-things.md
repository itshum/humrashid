Norman's core argument hasn't aged a day: when people struggle with an
object, the object failed, not the person. Doors that need a sign
telling you which way to push are bad doors. The same logic scales up
to software, dashboards, and every interface with a confusing default.

It's the closest thing this list has to a first-principles text. Read
it once for the vocabulary (affordances, signifiers, mapping,
feedback), then keep it around as a reference for arguing with anyone
who says "the user should just read the instructions."
